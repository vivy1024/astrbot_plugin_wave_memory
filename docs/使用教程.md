# WaveMemory 使用教程

从零装完一个 WaveMemory，到每天怎么用它。面向部署者（管理员），不面向群友。

- 版本：v5.1.3
- 前置：AstrBot ≥ 4.14.0、Python 3.10+
- 端口见证：`6185`（AstrBot 配置页）、`9876`（WaveMemory 管理台）

## 1. 十分钟装完

1. 把本插件目录放进 AstrBot 的 `data/plugins/`，重启 AstrBot，依赖自动安装。
2. 打开 `http://<服务器>:6185` → 插件配置 → WaveMemory，填两个必填项：

   | 配置项 | 用途 | 推荐值 |
   |---|---|---|
   | `embedding_provider_id` | 写入和召回都靠它 | `siliconflow/Qwen3-Embedding-0.6B` |
   | `tag_llm_provider_id` | 打标签、提炼黑话、风格 | 便宜能用的 flash 级模型即可 |

   `embedding_dimension` 默认 `1024`，与上面这个模型匹配；换模型要改。
3. 再重启一次，打开 `http://<服务器>:9876`，能进管理台就装完了。

> 没有这两个 provider，插件能起但只有骨架：入库靠 embedding，标签/黑话/风格靠 tag LLM。

---

## 2. 装完先做这 5 项检查

1. **`/api/health`**：浏览器开 `http://<服务器>:9876/api/health`。状态应为 `healthy`，并显示当前运行的版本和提交号。以后每次升级先核对这个。
2. **发一条群消息 @ Bot**，然后在 9876「注入观测台」找到这次注入：应看到 memory、facts、affinity 等通道的命中与耗时。
3. **管理台设密码**（`WebUI_Settings.webui_password`）：只要这台机器可能被局域网其他人碰到，就设上。
4. **确认备份在跑**：默认每日自动备份数据库到插件数据目录，保留 1 份。首次升级前务必手工多拷一份 `wave_memory.db` 到别的盘。
5. **（Docker 用户）确认记忆库在卷里**：`wave_memory.db` 应该在外挂数据卷，不要在容器层里——容器一删，记忆全没。

## 3. 三个运行模式怎么选

`Runtime_Settings.runtime_mode`：

| 模式 | 什么时候用 |
|---|---|
| `full`（默认） | WaveMemory 独立承担记忆 + 人格（心情、好感、黑话、信念……） |
| `memory_only` | 只要记忆注入，不要人格；或人格由别的人格插件负责 |
| `compat_only` | 已经装了 SelfLearning / ChatPlus，让 WaveMemory 只当记忆后端，避免两边一起注入 |

不确定就用 `full`。和别的记忆/人格插件共存时先看 README「与 SelfLearning / ChatPlus 共存」一节。

## 4. 记忆是怎么流动的

知道这条链，后面所有配置就知道在调什么了：

```
群友消息 ──► 入库（约 4 秒合并窗口，同时算 embedding）
           ──► 打标签（后台队列，tag LLM）
           ──► 入索引（热：HNSW 向量；冷：按标签映射回库）

有人跟 Bot 说话 ──► 注入编排器并行跑 14 个通道（几百毫秒）
   memory 语义召回 / fts5 原词命中 / facts 事实 / affinity 关系 /
   soul_state 心情 / jargon 黑话 / fewshot 风格 / book_lore 书设 /
   belief 信念 / persona 人格 / … ──► 按 token 预算合并进提示词

Bot 回复之后 ──► 事后记账（默认停 90 秒）：回看这段对话，
   记印象与好感结算、事实、黑话、人情、关切、心情变化

每晚 23 点后 ──► 每个说过话的群写一篇日记
日记写完 ──► 信念反思：形成 / 印证 / 放下 Bot 自己的看法
```

要点：

- **入库是全部，注入是筛选**。所有消息都会成为长期记忆（记忆只增不删）；检索只负责「想起来」，不是「记住」。
- **一次回复零 LLM 调用**。注入只花一次 embedding 查询 + 本地计算；模型只在「事后记账 / 日记 / 反思 / 打标签」时被调用。
- **写入有纪律**：单一写入口 + 事务发件箱。断电、重试不会写出两条一样的记忆。

## 5. 学习类开关：默认关，按需要打开

v5.1.1 里，所有「可能改变 Bot 行为」的新能力**默认都是关的**。决定权在你。位置：6185 配置页 → `Learning_Settings`（改完重启插件生效）。

| 开关 | 打开后的效果 | 建议 |
|---|---|---|
| `post_reply_bookkeeping_enabled`（默认开） | 事后记账，所有学习的数据来源 | 保持开 |
| `daily_diary_enabled`（默认开） | 每晚写日记，信念反思和关系小传的素材 | 保持开 |
| `auto_approve_enabled` | 证据齐全的事实 / 黑话自动生效；冲突仍进待审 | 建议开，省得天天点审核 |
| `belief_reflection_enabled` | 每晚日记后形成 / 印证 / 放下自己的看法 | 建议开（依赖日记） |
| `relationship_portrait_enabled` | 为群友写关系小传，注入时以小传为主 | 建议开（依赖日记） |
| `proactive_reply_enabled` | 关切驱动的主动开口：她惦记的人出现时主动问一句 | 先开，观察一周日志 |
| `reply_feedback_enabled` | 记录群友对她回复的反应（承接 / 纠正 / 没理） | 建议开，主动开口判断要用 |
| `expression_learning_enabled` | 提取群友的表达方式（先审核再用） | 可选 |
| `reply_rules_mode` | 开口规则：`off` / `shadow`（只观察）/ `enforce` | **先 `shadow`**，看记录合适再 `enforce` |
| `game_lesson_enabled` | 游戏经历写成经验卡 | 玩 Cortico 直播游戏才开 |

成本提示：记账每天上限 150 次调用、日记每群每天 1 次、反思每天 1 次；都可以在配置里压。后台每个任务用什么模型可在 `Model_Routing_Settings` 单独指定（比如全用便宜的 flash）。

## 6. 审核工作流：事实、黑话、风格

原则：**没有证据不进人格，进了人格你也可以撤**。三样东西的流水线一样：

```
Bot 现场提审 / 事后记账 / 后台挖掘
   → 待审核（pending）
   → 你在 9876 批准（approve）或拒绝（reject）
   → 批准的才会注入到回复里
```

- **事实**（9876「认知 → 事实」）：每条必须挂群友原话。可以单条批准 / 拒绝；冲突时可以「并存」或「取代」；待审核的行可以勾选后批量操作。已生效的事实不能勾选——那不是坏了，是它们不需要再审。
- **黑话**（9876「认知 → 黑话与口癖」）：自动挖掘的候选也会在待审里。批准前可以点开证据看原始聊天上下文。
- **风格样例**（9876「认知 → 风格样例」）：挑 Bot 的高光回复当范例，批准后用于风格注入。
- **看法**（9876「认知 → 看法」）：信念反思自动生效的，你看不顺眼可以一键否决；否决过的不会再生成。

开了 `auto_approve_enabled` 之后，大部分证据齐全的会直接生效，待审里只剩下需要你拿主意的（冲突、证据不足的）。

## 7. 每次回复，她在想什么

排查「她为什么说这个 / 为什么不记得」的三件工具：

1. **注入观测台**（9876「回复溯源 → 注入观测台」）：每次注入一条 trace。能看到 14 个通道各自命中了什么、为什么被跳过、花了多少时间、占了多少 token。回答「她当时看到了什么」。
2. **检索实验室**：拿同一句话对比不同检索开关（脉冲 / 残差金字塔 / EPA / 测地重排）的结果。回答「为什么想起的是这条」。
3. **Bot 主页**（9876 概览）：她今天的心情和原因、关系变化、新学到的事实与黑话。回答「她最近的状态」。

性能参考：注入中位数几百毫秒。超过 2 秒会在日志打慢注入警告；常见原因是 embedding 远端延迟，不是检索本身。

## 8. 日常运营：每天看什么

- **概览页待办**：待审事实 / 黑话、系统异常。
- **消息入库报警**：如果 Bot 收不到消息却正常运行（比如换了 QQ 号没绑定），9876 会标红。这个机制就是为了防止「悄悄丢记忆」。
- **标签覆盖**（记忆库 → 标签）：覆盖率低于正常值时按页上提示重新提取。
- **`/api/health`** 的版本号：确认线上跑的是你以为的那个提交。

## 9. 多 Bot：再加一个角色

9876「系统 → Bot 管理」→ 新增：

- 填身份（别名）、绑定平台账号（一个 Bot 可绑多个 QQ 号、Cortico 部署名、B 站直播间）；
- 保存**立即生效**，不用重启；
- 每个 Bot 的记忆、心情、信念、关切完全隔离——她只记得自己亲历的事，别的 Bot 见过的消息不会被召回；
- 想给某个 Bot 单独的书设语料、心情画像、通道覆盖、工具开关，都在同一页。

注意：**别再用 6185 静态配置里的 `MetaThinking_Bot1/Bot2` 槽位加 Bot**——那两个槽位只是历史兼容，升级后已被迁移，改了不生效。

## 10. 接 Cortico（直播）

WaveMemory 通过 9876 的 Runtime API 给 Cortico 用：

- Cortico 装 `cortico-world-wavememory` 扩展，填 9876 地址和令牌；
- 令牌在 9876「配置中心 → 外部接入」查看、复制、生成或自定义，改动立即生效；改了要同步到 Cortico 部署配置的 `wavememory.authToken` 并重启 Cortico。也可以用环境变量 `WAVEMEMORY_RUNTIME_TOKEN` 设置（优先级最高，此时管理台只读）。两处都没设时用的是写在开源代码里的公开默认值，管理台会标红提示——9876 对外开放前务必换掉；
- 注入走和 AstrBot **同一个编排器、同一份通道配置**，直播里想到的和 QQ 群里一样全；
- 直播弹幕、游戏经历、Bot 在直播里说的话会写回 WaveMemory，日记会用到这些素材；
- 注入观测台可按来源（AstrBot / Cortico）筛选。

## 11. 备份、升级与回滚

- **备份**：默认每日自动备份（保留 1 份），在插件数据目录。升级前手工把 `wave_memory.db` 拷到别的盘。
- **升级**：停 Bot → 备份 → 换上新代码 → 重启。数据库迁移（建新表、回填索引）在首次启动自动做，几秒到几分钟；升级须知看 CHANGELOG 对应版本节的「升级须知」。
- **回滚**：代码直接换回旧版即可；数据要回滚只能用升级前的备份（迁移只增不删，但升级后的新写入对旧版无意义）。
- **验证**：升级后先看 `/api/health` 的版本号，再到注入观测台看一次真实注入。

## 12. 常见问题 FAQ

**Q: 记忆页打不开 / 没数据？**
先看顶栏有没有选对 Bot 和群（所有需要作用域的页面共用顶栏选择）。再开 `/api/health` 看服务状态。

**Q: Bot 不调工具、不记人情不改好感？**
检查 `post_reply_bookkeeping_enabled` 是否开着（v5.1.1 起大部分记忆靠事后记账而不是现场调工具）。再看 9876 概览的「学习」统计，确认记账在跑、次数正常。

**Q: 群里的事实明明聊过，她说不记得 / 说错？**
大概率是事实还在「待审核」没被批准，或者注入时没命中。用检索实验室拿那句话试一下；再去注入观测台看那次回复 facts 通道为什么没命中。

**Q: 黑话批不了，点批准报 422？**
v5.1.1 已修复（旧版要求一个 WebUI 根本拿不到的溯源字段）。升级后硬刷新管理台页面。

**Q: 改完 9876 的通道配置，重启之后就没了？**
v5.1.1 已修复（配置改存数据库）。旧版本丢过一次的配置需要重新设置一次。

**Q: 注入太慢（日志老报慢注入）？**
开注入观测台看哪个通道慢。一般是 embedding 远端延迟（响应波动大、偶尔上秒），本地计算通常几十毫秒。可考虑换更近的 embedding 端点，或调大对应通道的 `timeout_ms`。

**Q: 只想要记忆，不想要人格 / 好感 / 黑话？**
`runtime_mode = memory_only`。保留消息采集、向量检索、基础注入和搜索 / 记住工具，其余高级通道全关。

**Q: 她老在群里主动说话打扰人？**
`proactive_reply_enabled` 关掉；或者保留但调紧频率（`proactive_group_min_gap_seconds`、`proactive_group_max_per_hour`、`proactive_quiet_hours`）。主动开口只由关切触发，没有别的来源。

**Q: 磁盘涨得快？**
正常。记忆只增不删（噪声记忆 7 天物理清理），十万级约 2GB 库 + 几百 MB 索引。老版本遗留的旧索引、事件流水在 v5.1.x 已清理；再往上就需要手工归档。

**Q: 怎么让她「更像这个群的人」？**
开事后记账 + 自动审核 + 关系小传 + 信念反思，跑一两周。黑话和风格样例头几天要手动批一批，把群的「语言环境」喂给她。人设正文 WaveMemory 不管——那在 AstrBot 的人格配置里。
